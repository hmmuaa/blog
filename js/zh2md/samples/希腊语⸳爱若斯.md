每列代表不同的调音方法，即辅音以何种方式产生。

每行则代表不同的调音部位，即辅音在口腔中哪个部分产生。

相同调音方法、调音部位的辅音，写在左侧格子的为清音，右侧格子的为浊音。

ʰ代表送气。

单辅音字母双写代表长辅音。

双辅音字母：ζ\[zd\]，ξ\[kʰs\]，ψ\[pʰs\]。

| 变音符号 | | 符号 | 发音 |
| --- | | --- | --- | --- |
| 气号 | 有气号 | ʽ | 单词开头的元音前有\[h\]音。以ρ开头的单词要使用有气号。 |
| 无气号 | ʼ | 单词开头的元音前没有\[h\]音。 |
| 重音符号 | 扬音符 | ´ | 表示短音的高调或长音的升调。扬音符出现在倒数第3、2、1的音节上。如果在倒数第3音节上，最后的音必须是短音。 |
| 抑音符 | \` | 当单词的倒数第1音节的扬音符后面紧跟非附缀词（自带重音），会替换为抑音符。表示半高调。 |
| 扬抑音符 | ˆ/~ | 表示长音的降调。抑扬音符出现在倒数第2、1音节上。如果在倒数第2音节上，最后的音必须是短音。 |
| 分音符 | | ¨ | 标注在两元音中第二个元音上方，表示两音不构成双元音。 |

| 标点符号 | 符号 | 用法             |
| -------- | ---- | ---------------- |
| 句号     | .    | 汉语的句号。     |
| 逗号     | ,    | 汉语的逗号，     |
| 分号     | ·    | 汉语的分号；     |
| 问号     | ;    | 汉语的问号？     |
| 省略号   | ᾽    | 此处有元音被省略 |
